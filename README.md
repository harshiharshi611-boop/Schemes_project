# SGSP - Student Government Scheme Portal

A full-stack web application that helps citizens discover, check eligibility for, 
and learn about government welfare schemes across categories like Education, 
Agriculture, Health, and Disability support.

## Features

- Browse 100+ government schemes across multiple categories
- Search and filter schemes
- View detailed scheme information (benefits, eligibility, required documents)
- Eligibility checker that matches users to relevant schemes based on their profile
- Admin panel to add, edit, and delete schemes (secured with JWT authentication)

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Authentication:** JWT (JSON Web Tokens), bcrypt for password hashing
